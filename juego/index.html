¿Cómo jugar?

1 Jugador: ← → moverte · Espacio / ↑ saltar (doble salto).
2 Jugadores: P1 con ← → ↑ · P2 con A D y W.
🎮 Mando: stick o cruceta para mover · A saltar · X / RB dash · Start pausar (mando 1 = P1, mando 2 = P2).
Salta sobre 🦝 mapaches, esquiva 🦔 erizos, 🐦 pájaros y 🐝 abejas. Dash: Shift / X (P2: Q). Usa 🟢 trampolines, cuidado con plataformas que se caen. Toca el 🚩 checkpoint y el 🌀 portal secreto.
